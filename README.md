# Thassos Guide

Πολύγλωσσος οδηγός για τη Θάσο (EN, EL, RO, BG, DE, TR, SR), φιλοξενείται δωρεάν στο Cloudflare Pages.

- `content.json`: όλα τα κείμενα σε 6 γλώσσες και οι φωτογραφίες (με φωτογράφο και άδεια)
- `build.py`: φτιάχνει τις σελίδες: `/` (αγγλικά), `/el/`, `/ro/`, `/bg/`, `/de/`, `/tr/`, `/sr/`, `sitemap.xml`, `robots.txt`

Για αλλαγές: διορθώνεις το `content.json` και τρέχεις `python3 build.py`.
